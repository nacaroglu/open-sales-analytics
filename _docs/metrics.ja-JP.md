# 指標カタログ

このカタログは `backend/app/analytics/shared/metrics.py` に従います。すべての範囲は両端を含みます。「利用不可」はファイルまたは比較に対してモジュールが回答できないこと、「データ不足」は指標のしきい値を満たさないこと、「ゼロ結果」は一致する行がない有効な回答を意味します。尺度は常に**総売上**であり、収益ではありません。

| キー | UI 名 | 式/分子 | 分母 | ウィンドウ、アンカー、注意事項 |
| --- | --- | --- | --- | --- |
| `first_purchase` | 初回購入 | 全履歴で最も早い注文日 | — | アップロードされた全履歴。識別済み注文がなければ利用不可 |
| `acquisition_cohort` | 獲得コホート | 初回購入を含む暦月 | — | 全履歴。月は月初日で表す |
| `gross_sales` | 総売上 | `SUM(quantity × unit_price)` | — | アクティブ範囲。売上がなければ 0 |
| `orders` | 個別注文数 | `COUNT(DISTINCT order_id)` | — | アクティブ範囲。注文がなければ 0 |
| `units_sold` | 販売個数 | `SUM(quantity)` | — | アクティブ範囲。個数がなければ 0 |
| `average_order_value` | 平均注文額 | 総売上 | 個別注文数 | アクティブ範囲。注文がなければ 0 |
| `change_percent` | 変化率 | `(current - comparison) / comparison × 100` | 比較値 | 選択した比較。基準値がゼロなら文言による状態と絶対変化を使用 |
| `product_revenue_share` | 総売上シェア | 商品総売上 | 総売上 | 互換キー。アクティブ範囲。合計がゼロなら利用不可 |
| `gross_sales_share` | 総売上シェア | 商品総売上 | 総売上 | アクティブ範囲。合計がゼロなら利用不可 |
| `cumulative_share` | 累積総売上シェア | 商品総売上の累計 | 総売上 | 商品の降順。合計がゼロなら利用不可 |
| `top_20_percent_share` | 上位 20% 商品シェア | 先頭 `ceil(0.2 × product_count)` 商品の総売上 | 総売上 | アクティブ範囲。合計がゼロなら利用不可 |
| `products_to_80_percent` | 総売上の 80% に達する商品数 | 条件を満たす最小の商品接頭集合 | 総売上 | アクティブ範囲。合計がゼロなら利用不可 |
| `product_growth` | 商品総売上成長 | 現在の総売上から比較総売上を減算 | — | 選択した比較。基準が利用不可なら利用不可 |
| `rising_products` | 上昇商品 | 総売上の変化が正の商品数 | — | 選択した比較。色だけでなく符号と文言を表示 |
| `falling_products` | 下降商品 | 総売上の変化が負の商品数 | — | 選択した比較。色だけでなく符号と文言を表示 |
| `new_products` | 新商品 | 現在には存在し、比較には存在しない | — | 選択した比較。比較なしなら利用不可 |
| `no_current_sales_products` | 現在売上のない商品 | 比較には存在し、現在には存在しない | — | 選択した比較。比較なしなら利用不可 |
| `unchanged_products` | 変化なしの商品 | 両期間の総売上が等しい | — | 選択した比較。比較なしなら利用不可 |
| `growth_rank_absolute_change` | 商品成長ランキング | 総売上の絶対変化で順位付け | — | 選択した比較。小さな基準値が支配しない |
| `dormancy` | 休眠商品 | アンカーから最終販売日までがウィンドウ以上の商品 | — | アンカーは選択範囲の終了日。ウィンドウは 30、60、90 日。履歴不足の場合あり |
| `cumulative_revenue_share` | 累積総売上シェア | 降順の商品総売上の累計 | 総売上 | 互換キー。アクティブ範囲。合計がゼロなら利用不可 |
| `weighted_unit_price` | 加重実現単価 | `SUM(quantity × unit_price)` | `SUM(quantity)` | 日次/週次/月次のアクティブ範囲バケット。個数なしなら利用不可。弾力性を示すものではない |
| `order_penetration` | 注文浸透率 | 商品を含む注文 | 全注文 | アクティブ範囲。注文なしはゼロ結果 |
| `basket_support` | バスケット支持度 | A と B の共通注文 | 対象バスケット注文 | 共通注文 10 件以上かつ支持度 0.1%。100 商品超の注文はここだけで除外 |
| `basket_confidence` | バスケット確信度 | A と B の共通注文 | 起点商品を含む注文 | 同じバスケットしきい値。方向が重要 |
| `basket_lift` | バスケットリフト | 方向付き確信度 | 宛先商品の支持度 | 同じバスケットしきい値。観測ペア率を宛先支持度と比較 |
| `identified_customers` | 識別済み顧客 | 一意の識別済み顧客 ID | — | アクティブ範囲。該当なしはゼロ結果 |
| `customer_coverage` | 顧客カバレッジ | 識別済みの個別注文 | 全個別注文 | データセット/範囲の注文カバレッジ。<50% は抑制、50–<80% は警告、≥80% は正常 |
| `new_vs_returning` | 新規対リピーター顧客総売上 | 全履歴の初回注文日で識別済み総売上を分割 | — | アクティブ範囲。初回注文アンカーには全履歴を使用 |
| `repeat_purchase` | リピート購入率 | 終了日までに個別注文が ≥2 件あるアクティブ顧客 | アクティブな識別済み顧客 | 範囲開始前の注文も数える。アクティブ顧客なしはデータ不足 |
| `days_between_purchases` | 購入間隔日数 | 連続する識別済み注文日の間隔の中央値 | — | 後の注文が範囲内であること。同日間隔は 0。固定の両端含有バケット |
| `cohort_retention` | コホート継続率 | コホート/月オフセットで継続した顧客 | 全履歴コホートサイズ | カットオフは選択終了日。未来セルは「未観測」であり 0 ではない |
| `historical_customer_value` | 過去顧客価値 | 顧客ごとの観測済み識別総売上。顧客別価値の中央値 | 識別済み顧客 | 観測値のみ、予測なし。コホート所属は全履歴の獲得月を使用 |
| `projected_customer_value` | 予測 12 か月顧客価値 | 観測価値と成熟コホート増分推定 | 識別済み顧客 | 推定のみ：履歴 18 か月、顧客 500、カバレッジ 70%、成熟コホート 5、期間 12 か月 |
| `rfm` | RFM セグメント | 相対的な最終購入、頻度、金額の五分位スコア。`FM = F + M` | 識別済み顧客 | 選択終了日まで。5 人未満は不足。このアップロード内の相対値でベンチマークではない |
| `rfm_drilldown` | RFM セグメント詳細 | 集計セグメント件数、総売上、固定分布 | セグメント合計 | 集計のみ。顧客識別子なし。同じ RFM 注意事項 |
| `purchase_frequency` | 購入頻度 | 一意の識別済み注文数でグループ化した顧客 | 終了日までの識別済み顧客 | 固定バケット 1, 2, 3, 4, 5, 6–10, 11–20, 21+ |
| `concentration` | 顧客集中度 | 上位 `ceil(N / 10)` 顧客の総売上 | 識別済み総売上 | アクティブ範囲。顧客 10 人未満または売上ゼロはデータ不足 |

予測は推定であり、保証でも因果・利益指標でもありません。顧客 ID は仮名化データであって匿名ではありません。顧客レスポンスはすべて集計のみで、一覧、検索、エクスポート、顧客ごとの値は公開しません。
